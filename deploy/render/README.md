# เดโม HomeLog บน Render (ฟรี)

ขึ้น HomeLog **โหมดเดโม** บน [Render](https://render.com) แผนฟรี ให้ลูกค้าเข้าเล่นได้ตลอดเวลาผ่านลิงก์
`https://homelog-demo.onrender.com` หรือชื่อใกล้เคียงที่ Render ตั้งให้ โดยไม่ต้องเปิดเครื่องของคุณทิ้งไว้

ค่าตั้งทั้งหมดอยู่ในไฟล์ [`render.yaml`](../../render.yaml) ที่ root ของ repo

## ลูกค้าจะเห็นอะไร

- ครอบครัวตัวอย่าง **"บ้านสุขใจ"** ที่ใช้ระบบมา 12 เดือน เป็นภาษาไทยและเงินบาททั้งหมด:
  ค่าใช้จ่ายประจำวัน, ค่าไฟ/ค่าน้ำพร้อมเลขมิเตอร์, บิลผ่อนบ้าน, โปรเจกต์, การหารค่าใช้จ่ายกับคู่ชีวิต, หนี้ระยะยาว และการแจ้งเตือน
- เข้าด้วยปุ่ม **เข้าสู่เดโม** ในหน้า login หรือใช้ `demo@homelog.app` / `demo`
- ลูกค้าทุกคนใช้บัญชีเดียวกัน ทุกอย่างกดเล่นได้ แต่ระบบห้ามเปลี่ยนรหัสผ่าน ห้ามลบบัญชี และห้ามสมัครสมาชิกใหม่
- ข้อมูล **รีเซ็ตกลับเป็นค่าตั้งต้นทุก 1 ชั่วโมง** และทุกครั้งที่ระบบเริ่มทำงานใหม่

## ข้อจำกัดของแผนฟรี

- **ถ้าไม่มีคนเข้า 15 นาที ระบบจะหลับ** คนแรกที่เข้ามาหลังจากนั้นต้องรอประมาณ 30–60 วินาทีให้ระบบตื่น
  ถ้าจะส่งลิงก์ให้ลูกค้า แนะนำให้เปิดลิงก์เองก่อน 1 ครั้ง
- ดิสก์ไม่ถาวร ข้อมูลที่ลูกค้าเพิ่มจะหายเมื่อระบบหลับหรือรีเซ็ต ซึ่งเป็นพฤติกรรมที่เดโมต้องการอยู่แล้ว
- แผนฟรีมีชั่วโมงใช้งานจำกัดต่อเดือน สำหรับเดโม 1 ตัวใช้ได้ทั้งเดือน ตรวจเงื่อนไขล่าสุดได้ในหน้าราคาของ Render
- **ห้ามใช้เก็บข้อมูลจริง**

## ขึ้นระบบครั้งแรก (ทำในเบราว์เซอร์ ไม่ต้องใช้คำสั่ง)

1. สมัครหรือเข้าสู่ระบบ [render.com](https://render.com) ด้วยบัญชี **GitHub** ที่มี repo `Warning502/homelog`
2. ที่ Dashboard กด **New +** → **Blueprint**
3. เลือก repo **Warning502/homelog** (ถ้าไม่เห็น ให้กด *Configure account* แล้วอนุญาตให้ Render เข้าถึง repo นี้)
4. Render จะอ่าน `render.yaml` และแสดงบริการ `homelog-demo` (แผน Free) → กด **Apply**
5. รอ build ประมาณ 5–15 นาที (build ทั้ง frontend และ backend จาก `Dockerfile`)
6. เมื่อสถานะเป็น **Live** กดลิงก์ `https://homelog-demo….onrender.com` ที่มุมบนของหน้าบริการ

`JWT_SECRET` Render สุ่มให้เองตอนสร้าง ไม่ต้องตั้ง

## อัปเดตเดโม

ตั้ง `autoDeploy: true` ไว้แล้ว ทุกครั้งที่ merge เข้า `main` Render จะ build และขึ้นเวอร์ชันใหม่ให้เอง
ถ้าต้องการสั่งเอง: หน้าบริการ → **Manual Deploy** → **Deploy latest commit**

## ใช้โดเมนของตัวเอง (ไม่บังคับ)

หน้าบริการ → **Settings** → **Custom Domains** → **Add Custom Domain** แล้วทำตามขั้นตอนตั้ง DNS ที่ Render แสดง

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วรอนาน | ระบบกำลังตื่นจากการหลับ รอไม่เกิน 1 นาที |
| build ล้มเหลว | ดูแท็บ **Logs** / **Events** ในหน้าบริการ แล้วส่งข้อความ error มาให้ตรวจ |
| หน้าเว็บขึ้นแต่ไม่มีปุ่ม "เข้าสู่เดโม" | ตรวจว่า `DEMO_MODE` เป็น `true` ใน **Environment** |

## สถิติผู้เข้าชม (ไม่บังคับ)

ค่าเริ่มต้นคือ **ไม่เก็บสถิติใด ๆ** ถ้าต้องการนับจำนวนผู้เข้าชมแบบไม่ใช้ cookie ให้สมัคร [GoatCounter](https://www.goatcounter.com/)
แล้วใส่รหัสไซต์ของคุณที่ `DEMO_GOATCOUNTER_SITE` ในหน้า **Environment** ของบริการ
